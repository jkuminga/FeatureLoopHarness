# Feature Index

실제 프로젝트를 시작할 때 이 템플릿을 프로젝트 내용으로 채우고 `status: completed`로 변경한다.

기능의 실제 진행 상태는 이 파일이 아니라 `docs/features/*/` 디렉토리 위치를 source of truth로 본다.
